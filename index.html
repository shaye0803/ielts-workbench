🗣️ 口语 Part 2 四大类串题

  • 人物类：admire的人 / 有趣的老人 / 帮助过你的人 → 一个「同事前辈」素材通吃
  • 地点类：安静的地方 / 想再去的城市 / 朋友的家 → 一个「旅行城市」素材通吃
  • 事件类：学到新技能 / 克服困难 / 难忘决定 → 用「备考雅思/学新软件」本身当素材
  • 物品类：重要物品 / 一件电子设备 / 收到的礼物 → 一个「手机/手表」素材通吃
准备4个万能素材 ≈ 覆盖80%题库，换题季只需微调。

✍️ 大作文9大高频话题池

教育（网课/大学价值）科技（AI/手机依赖）环境（污染/新能源）工作（远程/跳槽）政府投资取向城市化/住房健康（快餐/运动）媒体广告全球化/文化
每话题积累：核心词10个 + 正反论点各2 + 1个例子，比背范文有效。

✍️ 小作文7种图型清单

  • 动态线图/柱图（趋势词：surge, decline steadily…）
  • 静态柱图/饼图（比较词：account for, twice as…）
  • 表格（挑极值+分组概述）
  • 流程图（被动语态+顺序连接词）
  • 地图题（方位词+变迁表达）
  • 混合图（先分图后综合）
阶段一先攻动态图+静态图（占考试60%+）。
